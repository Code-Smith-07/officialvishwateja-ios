Getting Started

  • Pick a track (C, C++, Python or CS Foundations) from the Home tab or the world map, and work through its modules in order.
  • Each lesson has a short explanation and either a runnable code editor or a read-only example. Tap Run to compile and execute right on your device.
  • Answer the quiz at the end of each lesson to earn XP. Every module ends with a boss battle built from that module's quiz questions.
  • Your daily XP counts toward the goal ring on the Home tab. You can set your own daily goal in Settings.

Frequently Asked Questions

Does Code Quest need an internet connection?

No. The C, C++ and Python compilers, every lesson, and the whole curriculum are bundled in the app, so it works fully offline. See Privacy Policy for the one optional exception.

What is "Online extras" in Settings?

An opt-in toggle, off by default. If you turn it on and run a Python program that imports a package the app doesn't ship, like numpy or pandas, the app downloads it once (several MB) and keeps a copy on your device. With it off, those imports show a message telling you it needs to be turned on.

Where is my progress stored? Is it backed up anywhere?

Entirely on your device. There is no account and no server, so nothing syncs between devices. If you have iOS device backups turned on, your progress is included the same as any other app's data.

What happens if I delete the app?

Your progress, XP, achievements and any saved code are deleted with it, and there is no copy anywhere to restore from.

A program of mine won't run, or the app says a library isn't supported.

Some libraries need things a phone can't give a background process: a desktop window (tkinter, pygame), threads, or a persistent server. The app explains this in place when it detects one of these. For C/C++, no threads and no caught exceptions are supported (a throw ends the program).

My program seems to hang or the app warns about a runaway program.

Every run is watched by a time and memory limit you can adjust in Settings → Device care, so an infinite loop or runaway allocation is stopped rather than freezing your phone. Lower the limits there if you want tighter guardrails.

Can I reset my progress?

Yes. Go to Settings > Progress > Reset progress. It clears your XP, lessons, streak, badges and boss wins. Your code files stay.

Is there a subscription or any in-app purchase?

No. The app is free, with no advertising, no subscription and no in-app purchases.

What do I need to run it?

An iPhone or iPad running iOS 15 or later.
